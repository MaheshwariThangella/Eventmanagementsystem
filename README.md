# Event Planner Management System 🎉

## About the Project

The **Event Planner Management System** is a simple Python-based application developed using Object-Oriented Programming (OOP) and CSV file handling.

The main purpose of this project is to make event management easier. It allows administrators to manage events and customers to view, book, and manage their event bookings.

This project was developed as part of my academic learning to understand how Python concepts can be applied in a real-world application.

## Features

### Admin Features
- Admin registration and login
- Add new events
- View available events
- Update event details
- Delete events
- View registered customers
- View customer bookings

### Customer Features
- Customer registration and login
- View available events
- Search for events
- Book an event
- View personal bookings
- Cancel bookings

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- CSV File Handling

## OOP Concepts Used

## How to Run the Project

1. Install Python on your system.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Make sure the required CSV files are available.
5. Run the Python file using the terminal.

```bash
python main.py
```

## CSV Files

| File Name | Description |
|---|---|
| admin.csv | Stores admin details |
| customer.csv | Stores customer details |
| event.csv | Stores event information |
| bookings.csv | Stores booking details |

The application uses Python's `csv` module to read and write data into these files.
